# 我的世界网易版指令与 ID 查询（AstrBot）

AstrBot 插件：查询《我的世界》网易版常用指令及物品、方块、实体等标识符。

## 命令

- `/查询`：显示查询菜单
- `/查询 give`：查询指令用法
- `/查询 钻石`：搜索相关 ID
- `/查询 minecraft:zombie`：按命名空间 ID 搜索
- `/查询 指令 give`：只搜索指令
- `/查询 ID 钻石`：只搜索 ID 数据
- `/mc随机`：随机查看一条 ID 数据
- `/mc版本`：查看插件及数据库版本信息

## 安装

将插件目录 `astrbot_plugin_mc_nei` 放入 `AstrBot/data/plugins/`，在 AstrBot WebUI 中启用或重载插件。

## 数据说明

插件设计为读取内置 JSON 数据库，提供离线查询。网易版与国际版、不同游戏版本之间的指令及 ID 可能存在差异，请在实际游戏版本中验证具体命令。

## 版本

当前发布版本：v1.1.0。主查询命令统一为 `/查询`，保留旧版快捷命令以兼容原有用法。
